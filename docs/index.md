# SecObserve Provider

Manages configuration of a [SecObserve](https://github.com/SecObserve/SecObserve)
instance: products, product groups, branches, services, memberships,
authorization groups, rules, API import configurations and license policies.

Runtime data — observations, license components, scan results, metrics, VEX
documents — is intentionally out of scope. Those belong in the CI/CD pipeline
that runs the scanners, not in Terraform state.

## Requirements

- SecObserve 1.58 or a compatible release. The provider is generated
  against a pinned schema and warns when the instance's minor version differs.
- A **superuser** user API token. SecObserve filters list responses for
  non-superusers and rejects writes to users, general rules, settings and
  periodic tasks; with a non-superuser token resources appear to drift on
  every plan.

## Example Usage

```terraform
terraform {
  required_providers {
    secobserve = {
      source = "pflege-de-labs/secobserve"
    }
  }
}

# base_url and api_token are usually supplied via SECOBSERVE_BASE_URL and
# SECOBSERVE_API_TOKEN so the token never ends up in a state file or a diff.
provider "secobserve" {
  base_url = "https://secobserve-backend.example.com"
}
```

## Schema

### Optional

- `api_token` (String, Sensitive) User API token of a **superuser**. May also be set with the `SECOBSERVE_API_TOKEN` environment variable.

Create one with:

```console
curl -X POST "$SECOBSERVE_BASE_URL/api/authentication/create_user_api_token/" \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"...","name":"terraform"}'
```

A superuser token is required: non-superusers receive filtered list responses and cannot write users, general rules, settings or periodic tasks, which shows up as permanent unexplained drift.
- `base_url` (String) Base URL of the SecObserve **backend**, for example `https://secobserve-backend.example.com`. Note this is the backend, not the frontend URL. May also be set with the `SECOBSERVE_BASE_URL` environment variable.
- `insecure` (Boolean) Skip TLS certificate verification. Intended for local development against a self-signed certificate; never enable it against a production instance. May also be set with the `SECOBSERVE_INSECURE` environment variable.
- `timeout` (String) Per-request timeout as a Go duration, for example `60s`. Defaults to `30s`. Raise it if the instance is slow to answer large product lists.
